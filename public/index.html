      Управление с клавиатуры
      
      
      Раскладка не важна: клавиши работают и в русской раскладке. Клавиши действуют везде, кроме полей ввода и редактора кода: щёлкните по полю, если курсор стоит в тексте.
      
      
        
        
      • Команда из шапки («Команда»): WS вперёд/назад, AD поворот (или стрелки), Shift — медленно. Это роль Driver.
        • 
        
      • R/F — рука на Single Motor (Technician, прямое управление мотором). В матче рукой вручную можно двигать только пока робот целиком в зоне Technician (правило 17); пульт Driver руку не двигает (правило 14). G — мотор Grand Tree (Specialist), Shift+G — в обратную сторону. H — отправить покоящиеся фишки из зоны Specialist в Token Recycler.
        • 
        
      • Пока работает программа команды, клавиши становятся рычагами пультов и не мешают её командам: пульт Driver — W/S левый, ↑/↓ правый; пульт Specialist — R/F левый, T/G правый.
        • 
        
      • Второй игрок за той же клавиатурой (флажок на вкладке «Миссии») управляет другой командой: IK вперёд/назад, JL поворот, U/O рука, Y дерево, N recycler, правый Shift — медленно, правый Shift+Y — дерево в обратную сторону. С программой: I/K — левый рычаг Driver, O/L — правый.
        • 
        
      • Space — запустить/остановить программу команды из шапки (и после щелчка мышью по кнопке; кнопку, выбранную клавишей Tab, Space нажимает как обычно), Esc — остановить программы (в матче и у онлайн-хоста — только своей команды), P — пауза, Backspace — сброс поля (только в тренировке и когда выбрано поле), 1–4 — камеры.
        • 
        
      • Редактор кода: Tab — отступ. Чтобы уйти из редактора клавиатурой: Esc, затем Tab (или Shift+Tab). Ctrl+Enter — запустить.
        • 
        
      • Мышь: тащите фишки и робота — они упираются в борта и модели, фишка поднимается над тем, что под курсором. Колесо над роботом — поворот (с Shift — по 1°). Пустое место — вращение камеры.
        • 
      
      

      
      Две команды и программы
      
      
        
        
      • На вкладке «Код» выберите, чью программу правите: у красных и синих свой «Мой код», своя консоль и свои кнопки ▶/■. «▶ обе команды» запускает обе программы одновременно.
        • 
        
      • Выбор примера не стирает «Мой код». Если начать править пример, он станет «Моим кодом», а прежний сохранится в списке «Прежние версии «Моего кода»» (последние 6; версии из примеров вытесняются первыми).
        • 
        
      • Программа и физика идут «в замке»: результат не зависит от скорости 1×/4× и частоты кадров. Опрос датчиков и time.time() стоят чуть-чуть времени симуляции, поэтому циклы без sleep тоже работают честно.
        • 
        
      • Программа управляет только роботом своей команды: модули и переменные у команд раздельные. Python работает во вкладке, поэтому один непрерывный счёт без пауз (например, sum(range(10**8))) ограничен 1 с, а range() и списки — 1 000 000 элементов: для «вечного» цикла пишите while True:.
        • 
        
      • Неверный аргумент (строка вместо числа, nan, константа не той группы — например, MOVEMENT_DIRECTION_RIGHT в movement_turn_for_degrees) — понятная ошибка в строке вызова. Свойства устройства (.position, .yaw, .color…) читаются только после connect().
        • 
        
      • Ошибка подсвечивает строку вашей программы; exit(1) считается ошибкой, exit() — нормальным завершением.
        • 
      
      

      
      Матч
      
      
        
        
      • «Матч» → поставьте роботов мышью в зоны Technician → «Старт»: проверка (робот целиком в зоне, не выше 20.3 см), отсчёт 3 с, 2:30 по времени симуляции. Скорость и пауза во время матча заблокированы.
        • 
        
      • На 0:00 программы и моторы останавливаются, ввод замораживается, физика 2 с «досчитывает» положение фишек, затем счёт фиксируется. Итог виден на поле (через 4 с уходит в угол, × — скрыть), подробно — во вкладке «Судья».
        • 
        
      • Знак ≈ у счёта: фишки или механизмы ещё движутся, счёт может измениться.
        • 
        
      • Флажок «по старту матча» на вкладке «Код» запускает программу команды по сигналу старта.
        • 
      
      

      
      Python: модуль legoeducation
      
      
      Тот же API, что у LEGO Education Computer Science & AI. Программу можно перенести на робота: pip install legoeducation (Python 3.14+), в connect() укажите цвет и номер вашей Connection Card.
      
      
      import legoeducation as le
robot = le.DoubleMotor(); robot.connect()                    # ходовая робота
tree  = le.DoubleMotor(); tree.connect(device_name='tree')   # мотор Grand Tree
arm   = le.SingleMotor(); arm.connect()                      # навесное (Technician tool)
eye   = le.ColorSensor(); eye.connect()                      # датчик цвета вниз
pad   = le.Controller();  pad.connect()                      # пульт Driver
spec  = le.Controller();  spec.connect(device_name='specialist')

robot.movement_move_for_degrees(720, speed=50)
robot.movement_turn_for_degrees(90, direction=le.MOVEMENT_TURN_DIRECTION_RIGHT)
robot.movement_move_tank(40, 60); robot.movement_stop()
robot.motor[le.MOTOR_LEFT].position ; robot.imu_device.yaw
tree.movement_move_for_time(3000, speed=100)                 # дерево: те же команды
arm.motor_run_for_degrees(270, speed=60)                     # рука +90° (передача 1:3)
eye.sensor.color ; eye.sensor.reflection
pad.sensor.leftPercent ; spec.sensor.rightPercent
      
      
      Лимиты железа Future Edition проверяются в connect(): один Double Motor ходовой + Double Motor дерева, один Single Motor, один Color Sensor, два пульта (Driver и Specialist). Лишнее устройство — понятная ошибка.
      

      
      Допущения симулятора
      
      
        
        
      • Числовые значения констант (le.LEGO_COLOR_* и др.) в официальной документации не опубликованы — сравнивайте с константами, а не с числами.
        • 
        
      • Правый мотор «по часовой» = вперёд, левый «по часовой» = назад (моторы смотрят в разные стороны). Команды movement_* это учитывают сами.
        • 
        
      • movement_turn_for_degrees поворачивает по встроенному гироскопу; yaw растёт при повороте влево. Робот с ковшом длинный — разворачивайтесь, выехав из зоны Technician.
        • 
        
      • IMU: pitch растёт, когда нос поднимается, roll — когда правый бок опускается. Гироскоп (°/с) согласован с углами: gyroscopeX — скорость roll, gyroscopeY — pitch, gyroscopeZ — yaw. Знаки осей настоящего хаба не опубликованы — сверьте на своём роботе.
        • 
        
      • time.sleep_ms() и time.ticks_ms() работают, но это MicroPython: в CPython на компьютере их нет (симулятор предупредит).
        • 
        
      • Колёса проскальзывают, если робот упёрся в борт или другого робота: команды завершаются по энкодеру, времени или таймауту.
        • 
        
      • Расположение моделей снято с официальной Field Map (±2 см). 3D-модели упрощённые: официальных 3D-файлов сезона нет.
